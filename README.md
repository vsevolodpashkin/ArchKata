# ArchKata — Slidev-презентация

Презентация архитектурных решений аналитической платформы **NL → SQL → Отчёты**, сгенерированная на основе `design.md`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `slides.md` | Слайды (Markdown + Slidev-директивы) |
| `package.json` | Зависимости Slidev |
| `design.md` | Полный дизайн-документ |
| `component-diagram.puml` | Диаграмма компонентов (PlantUML) |
| `archkata-component-diagram.png` | Рендер диаграммы (встроен в слайд) |

## Запуск

### Требования
- Node.js >= 18
- npm (или bun / pnpm)

### Установка зависимостей

```bash
# npm
npm install

# или bun (быстрее)
bun install

# или pnpm
pnpm install
```

### Режим разработки (live-reload, откроется в браузере)

```bash
npm run dev
# или
bun run dev
```

Слайды будут доступны на `http://localhost:3030`.

### Сборка статического сайта

```bash
npm run build
```

Результат — в `dist/`, готов к деплою на любой статический хостинг.

### Экспорт в PDF

```bash
npm run export
```

Требует установленный [Playwright](https://playwright.dev/) или Chromium в системе.

| Клавиша | Действие |

| `→` / `Space` | Следующий слайд |
| `←` | Предыдущий слайд |
